# Week 2

This folder contains assignments and projects for week 2.
The focus is on advanced array methods, shopping cart simulation, and building a basic backend structure.

## Directories
- **Assignments-day3**: Advanced operations on arrays, banking transaction analyzer, movie streaming platform, and ToDo app.
- **Assignments-day4**: Library management system, deep/shallow copies, and array update operations.
- **E-commerce-shoppingCart**: Simulates an E-commerce cart experience.
- **backend_atp**: Initial setup for a backend application.
