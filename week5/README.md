Week 5: Frontend Development & Introduction to React
This directory contains a collection of projects and exercises focused on advanced CSS (Flexbox, Tables) and an introduction to building web applications using React.

Directory Structure
1. assignment/
Contains basic HTML and CSS practice projects.

Project 1 (1.html & style.css): Basic structure and styling practice.
Project 2 (2.html & style.css): Intermediate layout exercise.
Project 3 (3.html & style.css): Advanced styling and layout components.
2. flex1/
A practical example of using CSS Flexbox to create a responsive blog-style layout.

layout.html: The HTML structure featuring a navigation bar, main content area, and user profile cards.
style.css: CSS rules that utilize display: flex for alignment and media queries for responsiveness.
3. flexLayout/
Demonstrates a card-based layout using Flexbox, incorporating images directly as base64 strings.

flex.html: A centered container with three informational cards.
style.css: Defines shadows, rounded borders, and flex properties for the cards.
4. tables/
A deep dive into HTML table structures and their styling.

table1.html: Basic table with merged cells (colspan).
table2.html: Complex table layout with headers and footers.
table3.html: Advanced table styling and large dataset representation.
style.css, user.css, vat.css: Modular CSS files for different table styling requirements.
5. react-app-1/
The first introduction to React, built with Vite.

src/components/product.jsx: A reusable component to display product information.
App.jsx: The main entry point demonstrating component nesting.
6. react-app-2/
A more comprehensive React application featuring multiple components and state management.

src/components/:
Counter.jsx: A simple state-based counter component.
User.jsx: Displays individual user details.
UsersList.jsx: Renders a list of users.
NavBar.jsx & Footer.jsx: Standard layout components.
App.jsx: Orchestrates the interaction between these components.
